# Official hazard and environmental map features

Research date: October 2, 2026. Scope: Bay Area, New York, New Jersey, plus national layers. This is research and an implementation proposal; no application code or bulk dataset downloads were performed. Public service metadata was inspected through the web research tool. Availability, advertised query formats, and field schemas are distinguished below from successful sample queries, which have **not** been tested. A public endpoint is not itself a redistribution license.

## Recommended product

Add a **Property surroundings** map panel with individually selectable earthquake, flood, cleanup/landfill, and water layers. For a selected address, explain the mapped designation, source date, coverage, and official record link. Start with California earthquake investigation zones, national flood/Superfund context, and New Jersey contaminated-site records. Avoid a single combined “safe/unsafe” score: these sources describe different phenomena, have different spatial accuracy, and do not measure a household's exposure.

Useful examples: “Address point intersects a mapped liquefaction investigation zone”; “Nearest mapped cleanup-site location is approximately 0.7 miles away; this is a site location, not a contamination plume”; “Flood layer unavailable here.” Users can save several homes and compare these source-backed facts alongside the app's existing market and recorded-sale information.

## Endpoint catalog

The linked layer URLs are exact inspected metadata pages unless labeled **discovered only**. For feature layers, append `/query` for bounded requests, explicitly request `outSR=4326`, and paginate using the advertised capability. Native coordinate systems differ. The stated record limit is a per-response cap, not the dataset size. Copyright/agency credits below are minimum provenance guidance, not a substitute for checking applicable source terms before redistribution.

[CGS's program explanation](https://conservation.ca.gov/cgs/shma) documents incomplete statewide mapping, approximately 1:24,000 study scale, and geotechnical investigation requirements for many developments in mapped zones. Link the original map/report from each feature. The [official regulatory maps catalog](https://catalog.data.gov/dataset/earthquake-zones-of-required-investigation-maps-and-reports) identifies California DOC as publisher and a CC BY license link; retain that catalog metadata and confirm the license applies to the specific service/version used.

[USGS faults](https://www.usgs.gov/programs/earthquake-hazards/faults) provides downloadable GIS and KML. It also states that the database search retired February 26, 2026 and only limited fields have been maintained since January 12, 2017. Fault traces are context, not whole earthquake risk. USGS warns that excessive map zoom can imply more precision than the [underlying mapping supports](https://earthquake.usgs.gov/education/geologicmaps/qfaults.php). Use CGS investigation zones first in California. The [2023 national seismic hazard model release](https://www.usgs.gov/data/data-release-2023-us-50-state-national-seismic-hazard-model-overview) offers CC0 ground-motion datasets for later NY/NJ shaking context; a production-ready regional adapter/renderer was not verified here.

### California contamination and landfill sources

The official [GeoTracker catalog](https://catalog.data.gov/dataset/ground-water-water-quality-regulatory-information) exposes a **September 1, 2026** [CSV](https://data.ca.gov/dataset/c1ceaf0c-409c-4570-98c7-01f098c93ff0/resource/dc042197-e538-4a8b-9266-9c288aa72dcd/download/geotracker_sites_2026-09-01.csv) and [data dictionary](https://data.ca.gov/datastore/dictionary_download/dc042197-e538-4a8b-9266-9c288aa72dcd). Credit State Water Resources Control Board. Files/schema were not downloaded or inspected, and no explicit redistribution license was verified. Validate regional rows, coordinates, case type/status, date fields, dictionary, and terms before local ingestion. GeoTracker contains cleanup cases **and** permitted/non-case facilities, including land-disposal records; displaying every row as contamination would be wrong.

An official-hosted [GeoTracker GIS snapshot /371](https://gispublic.waterboards.ca.gov/portalserver/rest/services/Hosted/geotracker_sites_download/FeatureServer/371) advertises point GeoJSON, EPSG:3857, 75,000 cap and pagination. Fields include `global_id`, `business_n`, `case_type`, `status`, `status_dat`, coordinates/source, `potential_` contaminants, `potential1` media. However its [item description](https://gispublic.waterboards.ca.gov/portal/home/item.html?id=1db9a91e769c4030b1bf9da9cb3ac654) identifies a **January 2, 2023 snapshot**. Reject it as a current feed; its schema is not a substitute for verifying the 2026 CSV.

[DTSC EnviroStor](https://dtsc.ca.gov/your-envirostor/) describes cleanup, hazardous-waste permitting, and compliance download tools. No verified current bulk endpoint/schema/cadence was obtained; start with official record links and complete a separate source-validation step. An accessible 2021 ArcGIS mirror was rejected as stale. Similarly, [CalRecycle SWIS](https://www2.calrecycle.ca.gov/SolidWaste/Site/Search) is the authoritative landfill/facility lookup candidate, but a current official machine feed and reuse terms remain unverified. GeoTracker land-disposal records are not a complete landfill census. For fish advice, link [OEHHA](https://oehha.ca.gov/fish/species/all-fish-and-shellfish); no current authoritative advisory geometry feed was verified.

## Integration with this app

Read-only inspection of `web/src/MapPanel.jsx` finds React Leaflet `TileLayer`, `GeoJSON`, and `CircleMarker`, viewport updates on `moveend`, city/ZIP metrics, county boundary polygons, listing/sale pins, max zoom 14, and a global stale indicator. It has no hazard registry or overlay-specific status. This is an incremental extension, not a new map engine. `attributionControl` is disabled in this component; ensure visible provider attribution elsewhere when adding layers.

Proposed design:

1. Add overlay groups **Earthquake**, **Flood & coastal**, **Cleanup & landfills**, **Water advisories** with source-specific opacity, legend, dates, and coverage. Use Leaflet panes so fills remain below homes and clickable sites do not steal home selection. Keep economic metrics independently selectable.
2. Add an allowlisted backend source registry: provider/layer ID, geometry type, native CRS, query protocol, required attribution, terms URL, status fields, record cap, coverage source, max intended scale, cadence/vintage, and confidence notes. Do not accept arbitrary remote URLs from clients.
3. Reuse viewport bounds for debounced, cancellable bounded queries. Reproject to WGS84; paginate; deduplicate stable IDs; detect truncated responses; cap geometry complexity. Raster services use tile/export/identify adapters, not forced GeoJSON conversion. Regional caches should retain source metadata and be enabled only where terms permit.
4. Model result states separately: **mapped match**, **outside mapped designation within verified coverage**, **not mapped/assessed**, **source unavailable**, **partial/truncated**, **stale**. A blank response or failed request must not become “no hazard.” For point proximity say distance to the mapped location; use polygon distance/intersection where available without presenting it as plume/exposure.
5. The selected-home panel should display source record/class/status/date and a canonical official link, plus address-geocode precision. Address-point intersections are screening; parcel/building boundaries may differ. Preserve historical closed/no-action records and distinguish them from active cases.

## First release and acceptance checks

**First slice:** CGS's three regulatory overlays with quadrangle coverage, original map/report links, and source dates; national EPA Superfund sites; NJ contaminated-site points and CEA groundwater polygons. Add FEMA only after a bounded query verifies `/28` fields and `/0` coverage. NOAA scenario tiles are the next enhancement after tile/coverage/legend validation. NY remediation boundaries should remain official links until the secondary-distribution restriction is resolved. California cleanup ingestion should use the validated current CSV, not the 2023 snapshot.

Before release, verify a few known positives and outside/unmapped locations in each region against official viewers; service errors and pagination must produce visible partial/unavailable states. Check native CRS conversion, malformed coordinates, point-vs-polygon wording, release-date parsing, source attribution, and intended map scale. Test that a cleanup marker never says the home is contaminated, sea-level increments never silently acquire a year, and a water assessment never becomes a tap-water claim. These checks are meaningful because they validate the semantics most likely to mislead a home buyer.

Later additions: legally cleared NY boundaries/landfill points, current GeoTracker/EnviroStor/SWIS adapters, EPA streams/Brownfields, USGS shaking across NY/NJ, current agency fish/beach advisories, and saved-home comparison. Do not hide missing region/source coverage behind a nationwide risk score.
